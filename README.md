# قوات الطوارئ الخاصة - Version 4.1

موقع React + Vite جاهز للرفع على Railway.

## تشغيل محلي
```bash
npm install
npm run dev
```

## Railway
Build Command:
```bash
npm run build
```
Start Command:
```bash
npm run start
```

## طريقة الاستخدام
- ارفع صورة السيناريو.
- اختر نوع الحدث والموقع.
- اختر روم من اليمين.
- ألصق أسماء/منشنات الموجودين، كل شخص في سطر.
- اضغط إضافة للروم.
- اضغط + بجانب الأشخاص لاختيار المشاركين.
- في الإرسال انسخ التقرير أو احفظ الصورة.
